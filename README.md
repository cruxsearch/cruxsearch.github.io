# CruxSearch project page

Source of <https://cruxsearch.github.io>, the project page for *CruxSearch: Benchmarking Reasoning-Intensive Multimodal Agentic Search*.

The site is static HTML served by GitHub Pages from the `main` branch root.

- `index.html`: page content
- `static/css/style.css`: styles
- `static/js/main.js`: leaderboard data, sorting and filtering, figure zoom, BibTeX copy
- `static/img/`: figures exported from the paper
- `static/icons/`: model provider marks used in the leaderboard

Preview locally with `python3 -m http.server` and open <http://localhost:8000>.
